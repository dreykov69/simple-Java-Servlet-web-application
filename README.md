📌 Project Development Note


This repository shows a single commit with the complete project because:

1. Initial Development Environment Issues:
   - I spent significant time configuring Java 17, Tomcat 10, MySQL 8.0, and Maven
   - Multiple compatibility issues between Servlet API versions and Tomcat
   - Database connection troubleshooting and dependency conflicts

2. Learning Curve Challenges:
   - First experience with Java Servlets and JSP
   - Learning database connection pooling
   - Understanding the complete Servlet lifecycle
   - Figuring out Maven project structure and dependencies

3. Local Development vs GitHub:
   - I developed locally with extensive testing and debugging
   - Created multiple local branches for feature development
   - Only pushed to GitHub after ensuring everything worked perfectly
   - Wanted to avoid pushing broken/partial code

4. Project Timeline:
   - Days 1-2: Environment setup and learning Servlet basics
   - Days 3-4: Database design and connection implementation
   - Days 5-6: Servlet development and JSP integration
   - Days 7-8: Testing, debugging, and final polish

The single commit represents the culmination of 40+ hours of work....not a single day's effort.
